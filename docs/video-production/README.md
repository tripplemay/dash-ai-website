# 视频生产方法 v1.0

**可执行工具包已落地：**[本机工作台与 Skill 使用说明](WORKBENCH.md)。方法文档与可执行内核分开维护；原 manifest 模板仍是设计参考，不是运行时数据库格式。

整理日期：2026-09-22。依据：芯坐标宣传片的实际生产记录、用户验收、生成日志、后期脚本和交付工件。

**核心方法：先锁目标和叙事，再用小样验证难点；按依赖生产，按语义剪辑，分层验收，局部返工，最后从已批准源素材合成。**

本方法面向 AI 生成素材与程序化后期结合的品牌片、课程片和产品介绍片。它不是所有视频的唯一流程，也不是已经完成通用化的一键工具。真人访谈、口型同步、新闻纪实等需要另加专用规则。

## 标准流程

```text
需求与发布规格
  -> 文稿 / 分镜 / 时长预算 / 视觉锚点 / 声音短样
  -> 最难动作与前后衔接的小样
  -> 关键帧确认 -> 依赖就绪的镜头分批生成
  -> 下载完整性与时间基准检查
  -> 无声粗剪 + 连续旁白初配 -> 联合确认节奏
  -> 局部动作与接缝修复 -> 画面 / 旁白锁定
  -> 同源配乐 -> 信息 UI / 字幕 -> 最终混音与合成
  -> 技术验收 + 人工整片审看 + 目标设备检查
  -> 版本化交付与复盘
```

视觉锚点、音色小样和 UI 风格稿可以提前交叉推进；精确声画对位、配乐剪接、UI 帧时序依赖最终时间线。不要把所有工序机械串行，也不要在上游未确认时批量制作下游成品。

## 十条不可省略的规则

1. 项目开始就区分硬片长与期望片长；转场也占片长，不能只预算内容镜头。
2. 先审叙事因果和动作，再审光效；“好看”不等于“看得懂”。
3. 一个连续动作、一个连续排比句，优先作为一个制作单元。
4. 模型成功返回不是镜头通过；静帧通过不是动作通过；单段通过不是接缝或整片通过。
5. 首尾参考图不是像素锁，也不携带运动速度；检查真实输出端点和邻域。
6. 同一个声音预设不保证跨请求完全同声线；先连续主录，再从同源录音选取。
7. 旁白语义完整性优先于逐词卡画面。语义、画面、时长冲突必须显式决策。
8. 用户否决的版本不能因指标变好而自动转为通过；同一失败假设不无限修补。
9. 原始素材、批准版本不覆盖；审看片的前后上下文不能整条盲插回主片。
10. 技术检查、人工感知、发布条件分别签收；没有人工审听就不宣称断句和情感已通过。

## 已成熟与尚未闭环

- **可直接执行的方法**：带前后文的小样、单变量对照、来源与批准绑定、真实帧时序核验、局部替换、保留原件、流复制保护未修改轨道、技术与主观验收分开。
- **有条件复用的技术**：整帧几何和颜色匹配、调速、插帧、连续长段 TTS、分层 UI。参数必须根据新素材重新测定，不能照抄本片数值。
- **仍需验证的部分**：即梦最新整片声音及排比修订的主观终审、最终 UI 整片审美、正式目标设备、音乐商用适用范围。通用调度器和一键项目生产尚未实现。

本规范及工具包均未改动旧媒体、旧生产脚本、当前成片指针或全局记忆。工具包验证与作品感知验收分开；新建议在下一片验证后应以版本更新的方式修订，不把建议直接标成已有成功经验。
