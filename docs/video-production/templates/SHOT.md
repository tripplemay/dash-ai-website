## 生成规格

- 入口：图生 / 首尾参考 / 多关键帧 / 其他：
- 实际模型与工具版本：
- 精确提示词与参数文件：
- 输入图顺序、来源与 SHA：
- 预计费用 / 候选上限 / 停止条件：
- submit_id / 任务终态 / 下载路径 / 实际费用：
- 首帧、末帧、完整解码、实际帧数与时长检查：

## 提示词骨架

```text
保持：人物身份、场景布局、关键物体、色彩与参考构图。
起态：当前已经完成什么、尚未发生什么。
核心动作：一次明确动作，随后产生一个可辨认的结果。
摄影机：运动方向、速度变化、主体与摄影机的相对关系。
落态：结果稳定到什么状态；下一镜头需要什么出速。
约束：不新增人物、不重复动作、不提前完成结果、无可读伪文字。
```

这是表达结构，不是模型必然遵从的保证；不把完整故事、光效与动作数量无限叠加到一个短镜头。
