## 7. 合片清单

- [ ] 所有引用是已选文件，不按“最新文件名”猜测。
- [ ] 帧号 0 起算、区间 `[start,end)`，音频用整数采样；基线 SHA 正确。
- [ ] 核心替换与两侧处理范围完整，审看上下文不会重复插入。
- [ ] 预计净增减帧数和总时长已计算。
- [ ] 直接读取原始 / 无损来源与参数，不二次加工压缩审看片。
- [ ] 未变范围和已批准片段有回归检查。
- [ ] 新版单独输出，旧版和原指针保留可追溯记录。

## 8. 发布清单

- [ ] 完整解码、尺寸、帧率、帧数、时码、音轨和峰值检查通过。
- [ ] 正常速度静音审画面，正常速度有声审完整叙事与混音。
- [ ] 语义完整，专名和简称读音确认，无长空隙或切字问题。
- [ ] UI / 字幕时序、阅读、遮挡和事实正确；重新配音后已复核。
- [ ] 使用权、目标设备和需要的循环播放验收完成。
- [ ] 发布版本及 SHA 明确，人工批准与技术结果分开记录。
- [ ] 交付 MP4、所需分轨 / 图层、manifest、报告及已知限制。
