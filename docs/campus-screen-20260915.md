## 视觉与技术

- 保留原有深色科技风；统一 1920 x 1080 画布、页眉、字体、网格、图标、页脚与进度线。
- 深靛蓝底色，冰蓝与青色信息线条，珊瑚橙重点标记。
- 文案、数字、流程、连线与图标使用 HTML / CSS / SVG，不将中文正文烘焙进生成图片。
- 主视觉生成通道为 AIGC Gateway，模型名 `gpt-image-2`，实际采用 8 张新图。提示词在 `output/imagegen/campus-screen-20260915/prompts.json`。
- 咨询页的独立视觉两次遇到服务拥堵，未采用失败结果；改用已成功生成的学习路径主视觉，与“找到学习起点”的主题呼应，没有切换模型。
- 原科技封面与三个符合主题的未来感体验插画保留；传统工作台、手作课堂及灰色背景换为新科技概念视觉。
- 网页使用 WebP，原始 PNG 独立保留。图片不作为真实学员、校区实拍或认证凭据。
- 画布按浏览器尺寸等比完整缩放；非 16:9 屏幕留边，不裁掉正文。

## 播放与维护

- 默认自动循环，九域总览页 18 秒、认证介绍页 20 秒、国内外赛事页 24 秒，其余每页 11-15 秒，一轮 210 秒。
- `?slide=5&paused=1`：从第 5 页暂停预览；`slide` 超范围会归一到有效页面。
- 左右方向键 / PageUp / PageDown 翻页，Home / End 首尾页，空格播放或暂停，F 切换全屏，Esc 退出。
- 手动翻页自动暂停；页面不可见时暂停计时。触屏支持左右滑动。
- 控制条在鼠标活动、触摸或键盘操作时出现；静置后隐藏，键盘焦点在控制条内时保留可见。
- 文案与图片映射：`src/lib/campus-screen.ts`。
- 版式与播放器：`src/components/campus-screen.tsx`、`src/components/campus-screen.module.css`。
